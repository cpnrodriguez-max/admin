Paso 0 · Conseguir los PDF desde AFIP (F12)

No tengo forma de entrar a tu cuenta de AFIP con tu Clave Fiscal, así que este paso lo hacés vos, en tu propio navegador ya logueado. Dos formas:

Opción A — Manual (más segura, recomendada)

  1. Entrá a la consulta de Cartas de Porte Electrónicas en AFIP/ARCA con tu Clave Fiscal.
  2. Descargá el PDF de cada CTG que te interese (botón "Ver CP" / "Imprimir").
  3. Soltá todos los PDF en la zona de carga de abajo (Paso 1).

Opción B — Script de consola (F12), en lote y con avance de página automático

Verificado en cpea-app.afip.gob.ar/cpe-web → pantalla Consulta de Solicitadas (#/consultar-solicitadas), paginado tipo Bootstrap (‹ 1 2 3 … ›). Con esa pantalla abierta en la página 1, presioná F12 → pestaña Console, pegá este script y Enter. Descarga los 10 PDF de la página actual, pasa solo a la página siguiente y repite hasta que no haya más:

(async function () {
  const ESPERA_ENTRE_DESCARGAS = 2000;
  const ESPERA_CAMBIO_PAGINA = 2500;
  const MAX_PAGINAS = 30; // tope de seguridad

  function botonSiguiente() {
    const links = [...document.querySelectorAll('.page-link')];
    const sig = links.find(el => el.textContent.trim() === '›');
    if (!sig) return null;
    const li = sig.closest('.page-item');
    if (li && li.classList.contains('disabled')) return null;
    return sig;
  }

  let pagina = 1;
  while (pagina <= MAX_PAGINAS) {
    const botones = [...document.querySelectorAll('button.fa-print, button[title="Imprimir"]')];
    console.log(`--- Página ${pagina}: ${botones.length} Cartas de Porte ---`);
    for (let i = 0; i < botones.length; i++) {
      botones[i].click();
      console.log(`  (${i + 1}/${botones.length}) descarga disparada`);
      await new Promise(r => setTimeout(r, ESPERA_ENTRE_DESCARGAS));
    }

    const sig = botonSiguiente();
    if (!sig) { console.log('No hay más páginas. Listo.'); break; }
    sig.click();
    pagina++;
    console.log(`Avanzando a la página ${pagina}...`);
    await new Promise(r => setTimeout(r, ESPERA_CAMBIO_PAGINA));
  }
})();

Notas: probalo primero con MAX_PAGINAS = 2 para confirmar que avanza bien antes de dejarlo correr las ~20 páginas completas. Chrome puede bloquear descargas automáticas después de varias seguidas: si dejan de bajar, fijate si apareció un aviso arriba del navegador y tocá "Permitir". El botón "›" y la clase .page-link son de un componente de paginación Bootstrap estándar; si AFIP cambia el diseño de la pantalla, avisame con una captura nueva del botón para actualizar el selector. Nunca compartas tu Clave Fiscal conmigo ni con ningún script.
