Paso 0 · Conseguir los PDF desde AFIP (F12)

No tengo forma de entrar a tu cuenta de AFIP con tu Clave Fiscal, así que este paso lo hacés vos, en tu propio navegador ya logueado. Dos formas:

Opción A — Manual (más segura, recomendada)

  1. Entrá a la consulta de Cartas de Porte Electrónicas en AFIP/ARCA con tu Clave Fiscal.
  2. Descargá el PDF de cada CTG que te interese (botón "Ver CP" / "Imprimir").
  3. Soltá todos los PDF en la zona de carga de abajo (Paso 1).

Opción B — Script de consola (F12), en lote

Verificado en cpea-app.afip.gob.ar/cpe-web → pantalla Consulta de Solicitadas (#/consultar-solicitadas). Con esa pantalla abierta y la página de 10 resultados a la vista, presioná F12 → pestaña Console, pegá este script y Enter. Clickea los 10 botones "Imprimir" de la página actual (se descargan directo, sin diálogo extra), respetando tu sesión ya iniciada:

(async function () {
  const botones = [...document.querySelectorAll('button.fa-print, button[title="Imprimir"]')];
  console.log('Botones "Imprimir" encontrados:', botones.length);
  if (!botones.length) {
    console.log('No encontré nada. Click derecho sobre el botón "Imprimir" de una fila > Inspeccionar, y ajustá el selector de arriba con lo que veas ahí.');
    return;
  }
  for (let i = 0; i < botones.length; i++) {
    botones[i].click();
    console.log(`(${i + 1}/${botones.length}) click disparado`);
    await new Promise(r => setTimeout(r, 2000));
  }
  console.log('Listo esta página. Andá a la página siguiente (10 resultados más) y volvé a correr este mismo script.');
})();

Notas: el script solo procesa la página de 10 resultados visible; repetilo en cada página hasta terminar. Si AFIP cambia el diseño de esa pantalla el selector puede dejar de funcionar — en ese caso inspeccioná de nuevo el botón "Imprimir" y avisame para actualizarlo. Nunca compartas tu Clave Fiscal conmigo ni con ningún script.
